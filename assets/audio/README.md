# Lokale muziek voor Neon City

Plaats hier afzonderlijk `city-ambient.mp3` (stad) en `energy-core.mp3` (kern).
De bestanden zijn aanwezig op deze computer en worden niet hernoemd of gewijzigd.
MP3, WAV en M4A in deze map worden door `.gitignore` uitgesloten van Git/GitHub.
Op een andere computer moeten de muziekbestanden apart worden overgezet.
Configureerbare relatieve URL's staan in `js/audio/audio-settings.js`.
De browser leest ze alleen via de lokale Python-webserver nadat Start audio
is ingedrukt. Geen externe muziekservice of upload.
